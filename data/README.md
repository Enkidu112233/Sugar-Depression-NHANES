# Download the original NHANES data

The included processed DTA files support the default analysis. To rebuild, create the two destination directories shown below and save each original XPT under the exact filename in the list. The revised scripts compute dietary measures from the Total Nutrient Intakes files. The 2017–2018 script also imports the two Individual Foods files, as supplied, so both are listed as required inputs for that script.

If a direct link changes, use the official [2017–2018](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?Cycle=2017-2018) or [2021–2023](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?Cycle=2021-2023) catalogue and look up the exact file code. Read the [NCHS data user agreement](https://www.cdc.gov/nchs/policy/data-user-agreement.html).

The SHA-256 and byte sizes in `raw_manifest.csv` describe the local reference files used to test this package. CDC can update files. `python tools/verify_package.py --raw` checks that your downloaded inputs match these references.
